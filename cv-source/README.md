# CV source

LaTeX source exported from Kai Ma's Overleaf project, with the personal homepage link added to the contact header.

- Main document: `resume.tex`
- Document class: `resume.cls`
- Public PDF: https://badbeers.github.io/CV.pdf

Compile with XeLaTeX (twice) in this directory, or use Tectonic:

```sh
tectonic resume.tex
```

After checking the generated PDF, copy `resume.pdf` to `../CV.pdf` and commit both source and PDF. Overleaf edits are not automatically synchronized with this repository.
